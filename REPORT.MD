
# Project Report: Nexora AI Academy

## 1. Introduction
Nexora AI Academy is a modern online learning platform designed to provide an interactive and engaging learning experience. It focuses on AI and technology-related courses.

## 2. Project Objectives
- To develop a modern online learning platform.
- To provide easy access to online courses.
- To allow users to search and filter courses.
- To create a user-friendly interface.
- To provide an interactive learning experience.

## 3. Technologies Used
- React.js
- TypeScript
- Vite
- Tailwind CSS
- Three.js
- React Three Fiber
- Framer Motion
- Lucide React

## 4. Main Features
- Modern Homepage
- Animated 3D Hero Section
- Course Marketplace
- Course Search Functionality
- Category Filters
- Difficulty Filters
- Course Preview Modal
- Pricing Plans
- Checkout Modal
- Responsive Design

## 5. Project Working
Users can explore different courses, search for specific courses, apply category and difficulty filters, and view course details. The platform also provides pricing information and an interactive checkout interface.

## 6. Installation and Setup

### Step 1: Clone Repository
```bash
git clone https://github.com/creativestories006-cmyk/nexors.git
```

### Step 2: Open Project Folder
```bash
cd nexors
```

### Step 3: Install Dependencies
```bash
npm install
```

### Step 4: Run Project
```bash
npm run dev
```
